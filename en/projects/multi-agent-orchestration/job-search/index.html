Multi-Agent AI Orchestration

Job search agent

My own job search, automated end to end.

The job search agent runs my own job search: it collects Microsoft 365, Modern Workplace and Microsoft security offers in France, scores them against my resume, applies automatically on HelloWork within a daily cap, then tracks the replies.

Trust level
L4 · capped autonomy
Model
Claude Haiku
Trigger
7 runs per day
  • Hermes Agent
  • Claude Haiku
  • Python
  • Browser automation
  • Telegram

Automated actions

  1. Daily · 8:00 amMulti-source collection, scoring and summary of new offers
  2. 9 am, 12 pm, 3 pm, 6 pmAutomatic HelloWork applications, from the best-scored offers down
  3. Daily · 6:30 pmReading recruiter replies received by email
  4. Daily · 6:45 pmReport on the day’s applications

How it works

Collection

  • Adzuna (API), HelloWork, Remotive, Lever, Greenhouse, Workable, LinkedIn
  • Deduplication by URL

Scoring

  • Weights: title 30%, skills 40%, location 20%, freshness 10%
  • Île-de-France first, off-target offers discarded

Applying

  • Sign-in through a credential vault
  • Form, resume, verification code
  • Checked in “my applications” before the offer is marked as sent

Guardrails

  • Cap of 25 applications per day.
  • Never applies automatically on a recruiter’s own site: flagged, I apply myself.
  • Any email or message to a recruiter requires my explicit approval.
  • No guessed fields: unknown data stays “unknown”.
