Context and goal

A fintech’s customer support receives repetitive requests across several channels and in several languages.

The goal: answer routine requests automatically without losing control, and hand over to a human whenever needed.

From customer message to checked reply

Architecture · Conceptual diagram

How it works

Intake

  • WhatsApp and web chat messages centralized in Chatwoot
  • Handled by the AI agent

Reply

  • Answers routine requests in six languages
  • Every reply is checked before sending

Escalation

  • Handover to a human when in doubt or in sensitive situations
  • Telegram alert

Security and guardrails

  • Every reply is checked before sending.
  • The model has no access to tokens or sensitive tools.
  • Escalation to a human when in doubt.
  • Measures designed to reduce prompt injection risks — no protection is absolute.
  • Human approval for situations that require it.

Results

The system has handled 208 conversations and generated more than 680 automated replies, with support for six languages. More than 400 automated tests help verify expected behavior.
