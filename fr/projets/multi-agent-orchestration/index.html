Système auto-hébergé · Linux

Multi-Agent AI Orchestration

Orchestrer plusieurs agents spécialisés avec un contrôle humain des actions.

Hébergé sur un serveur Linux, ce système repose sur un agent manager qui coordonne quatre agents spécialisés. Le pilotage et la supervision passent par Telegram, avec une séparation des rôles et une validation humaine avant toute action externe.

Catégorie
Système auto-hébergé
Statut
Auto-hébergé sur un serveur Linux personnel
  • Hermes Agent
  • Linux
  • Python
  • API LLM
  • Telegram

Contexte et objectif

Automatiser des tâches récurrentes de veille, de recherche d’emploi, de prospection et de supervision, tout en gardant la main sur chaque action qui sort du système.

Un manager, quatre agents spécialisés

Architecture · Schéma conceptuel

Principes d’architecture

Organisation

  • Un agent manager
  • Quatre agents spécialisés
  • Séparation des responsabilités

Contrôle

  • Aucune action externe sans validation humaine
  • Supervision via Telegram

Socle

  • Serveur Linux auto-hébergé
  • API LLM

Sécurité

  • Moindre privilège : chaque agent ne dispose que de ce dont il a besoin.
  • Séparation des responsabilités entre le manager et les agents spécialisés.
  • Aucune action externe sans validation humaine.

Ce que le système apporte

Un cadre pour déléguer des tâches récurrentes à des agents spécialisés, coordonnés par un manager, sans renoncer au contrôle humain des actions externes.
